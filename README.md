- 📊 **Excel（51種）**: データ端ジャンプ・範囲選択、可視セル選択、フラッシュフィル、絶対参照（`F4`）、オートSUM、名前定義、数式トレース、値のみ貼り付け、表示形式（カンマ・日付・通貨・%）、行・列の非表示＆グループ化、ウィンドウ枠固定、列幅自動調整、テーブル・フィルタ・ピボット・グラフ作成など
