# ⌨️ Windows ショートカットキー パーフェクトガイド

Windows 11・Excel・Word・ブラウザ（Chrome / Edge）・基本共通のPCショートカットキー全121種を、カテゴリ・用途・重要度別に完全網羅したシンプル＆高速検索サイトです。

## ✨ 主な特徴

- **5大カテゴリ ＋ サブカテゴリ分類（全121種）**
  - 🪟 **Windows 11**: ウィンドウ整列、スナップレイアウト、仮想デスクトップ、スクショ、クリップボード履歴、エクスプローラーなど
  - 📊 **Excel**: セル移動・範囲選択、データ入力、フラッシュフィル、絶対参照、オートSUM、書式設定、テーブル・フィルタ操作など
  - 📝 **Word**: 文字装飾、書式クリア、段落配置、改ページ、見出しスタイル、段落の上下移動、校閲など
  - 🌐 **ブラウザ (Chrome / Edge)**: タブ操作、閉じたタブの復元、アドレスバー操作、スーパーリロード、履歴・ブックマークなど
  - ⌨️ **共通・基本**: コピー＆ペースト、書式なし貼り付け、元に戻す/やり直し、F7〜F10変換など
- **重要度ランク絞り込み**: `★★★ 必須・最重要` / `★★☆ 便利・時短` / `★☆☆ 玄人ワザ`
- **🎹 キー入力で逆引きモード**: 実際にキーボードを押して該当するショートカットを即座に検索
- **表示切替 ＆ チートシート印刷**: 解説付き「カード表示」と一覧「早見表」の切り替え、A4印刷・PDF出力対応
- **ダークモード ＆ お気に入り保存**: ブラウザの LocalStorage によるマイリスト保存対応

## 🚀 使い方

`index.html` をブラウザで開くだけでそのまま動作します（外部ライブラリ・ビルド不要）。
